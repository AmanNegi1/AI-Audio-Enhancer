Calculus Fundamentals

1. Limits & Continuity

A limit describes what value a function approaches as its input gets closer to a target: $$\lim_{x \to c} f(x) = L$$ For a function to be continuous at $c$, the limit must exist and equal the actual function value: $\lim_{x \to c} f(x) = f(c)$.

2. Differentiability

A derivative measures the instantaneous rate of change (the slope of the tangent line): $$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$ If the slope changes abruptly (like in the absolute value function $|x|$ at $x=0$), the function is not differentiable there.

3. Maxima & Minima

To optimize (find the best/worst state), we look for critical points where the derivative $f'(x) = 0$. - **First Derivative Test**: If $f'(x)$ changes sign, it is a local extrema. - **Second Derivative Test**: If $f''(x) > 0$ at a critical point, it is a minimum (concave up). If $f''(x) < 0$, it is a maximum (concave down).

LU Decomposition Explained

LU decomposition factors a matrix $A$ into a Lower triangular matrix $L$ and an Upper triangular matrix $U$: $$A = LU$$ This is heavily used in computing to solve linear systems $A\vec{x} = \vec{b}$ efficiently via forward and back substitution, rather than computing $A^{-1}$ which is computationally expensive.

The Real Existence of Math in AI

Artificial Intelligence is not magic; it is the concrete application of Calculus, Linear Algebra, and Probability. Here is exactly how they compose the neural systems powering modern models:

Linear Algebra (Representations)

What it is: Tensors, vectors, and matrices.

In AI: Every input (image pixels, tokenized words) is represented as a high-dimensional vector. Neural network layer weights are matrices. The core feedforward operation of a network is simply matrix multiplication followed by an activation function: $$\vec{h} = \sigma(W\vec{x} + \vec{b})$$ GPUs are specifically designed to perform billions of these matrix operations concurrently.

Calculus (Learning)

What it is: Derivatives, partial derivatives, and the Chain Rule.

In AI: How does an AI "learn"? It tries to minimize a Loss (error) function using Gradient Descent. The gradient is a vector of partial derivatives pointing in the direction of steepest increase. By calculating derivatives, we know how to adjust weights to reduce errors: $$W \leftarrow W - \eta \frac{\partial L}{\partial W}$$ The **Chain Rule** allows us to propagate this derivative backwards from the output layer to the input layer (Backpropagation).

Probability (Uncertainty)

What it is: Distributions, entropy, and likelihood.

In AI: A LLM doesn't "know" a fact; it assigns a probability distribution over the next word in a vocabulary. Loss functions (like Cross-Entropy) measure the difference between the predicted probability distribution and the true distribution. Generative models (like GANs or Diffusion models) learn to sample from high-dimensional probability distributions representing realistic data (like natural images).

Infrastructure Components

1. Load Balancer

Distributes incoming traffic across healthy web servers (Server A & B). Toggling Server B down directs 100% of traffic to Server A, demonstrating high availability and health check redirections.

2. Redis Cache

Fast in-memory database. Read requests query Redis first. - **Cache Hit**: Data is in cache; request returns immediately (fast). - **Cache Miss**: Request falls back to Database, queries disk, stores data in Redis, then returns (slower).

3. Database Replication (Primary/Replica)

Writes are directed to the **Primary DB** to maintain data integrity. Reads are directed to **Replica DBs** to distribute query loads. Changes are replicated asynchronously from Primary to Replica.
